# CS2 ЛИГ · Season 3

Статик сайт (HTML / CSS / JS). Хөгжүүлэгчийн сервер хэрэггүй.

## Засах газар
- `script.js` дээд талд: Season 3-ийн огноо (`SEASON_START`), багууд, map, хуваарь.
- `style.css`: өнгө (`--accent`) болон загвар.
- `assets/`: багийн постерууд.

## Дотроо харах
VS Code дээр "Live Server" extension-оор `index.html`-ийг нээнэ, эсвэл `npx serve`.
